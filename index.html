Частный репозиторий приложения

TiredVPN
для F-Droid

Здесь публикуются подписанные разработчиком APK TiredVPN. Это отдельный репозиторий проекта, он не входит в каталог F-Droid.org.

Добавить репозиторий в F-Droid

Откройте F-Droid → Настройки → Репозитории → «+» и добавьте адрес с отпечатком:

https://igor04091968.github.io/tiredvpn-fdroid/fdroid/repo?fingerprint=AD9A2A670A24AEBF3C2E4D1106492DF91D4303F9BD33BBD444EB9ED11C32911D

Открыть адрес репозитория

Сверьте отпечаток после добавления. Он защищает каталог от подмены. Отпечаток APK-подписи приложения отдельный и сохранён в индексе.

Установить APK напрямую

Текущая версия: 1.12.1-igor.8 (код версии 35), Android 9 и новее.

Скачать APK с GitHub

SHA-256: 36370e51165efed3d20437fd7cd2c85acfc807bc6ebf0814d2613e0803358117

Обновления

После добавления репозитория обновления будут появляться в F-Droid при обновлении каталога. Новые версии добавляются владельцем проекта вручную. APK подписывается ключом TiredVPN; индекс репозитория подписан отдельным ключом.
