# TiredVPN F-Droid repository

Static custom repository for the F-Droid client. The published APK is signed with the existing TiredVPN app key. Repository index signing uses a distinct private key held by the maintainer.

Repository URL: https://igor04091968.github.io/tiredvpn-fdroid/fdroid/repo

Do not publish `config.yml`, the repo keystore, passwords, or private-key backups. Only the site files and generated `fdroid/repo/` directory are public.
